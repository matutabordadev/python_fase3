# Menú de verificación de edad en Python

Programa en Python que implementa un menú interactivo por consola para verificar la edad de un usuario, validando entradas incorrectas y controlando el flujo del programa mediante bucles y condicionales.

## Funcionalidades

- Menú interactivo con opciones
- Verificación de edad del usuario
- Validación de entradas (solo números)
- Control de rango válido de edad (1 a 120)
- Restricción de acceso según la edad
- Opción para salir del programa de forma segura

## Cómo usar el programa

1. Ejecutar el archivo `.py`
2. Ingresar el nombre del usuario
3. Seleccionar una opción del menú
4. Seguir las instrucciones que aparecen en pantalla

## Objetivo del proyecto

Proyecto realizado con fines educativos para practicar lógica de programación en Python, uso de bucles, condicionales y validación de datos ingresados por el usuario.
